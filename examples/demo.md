# Markdown в окне приложения

Открой этот файл через **mdread**, измени текст и сохрани — страница обновится автоматически.

## Возможности

- Заголовки, **жирный текст** и *курсив*
- [Ссылки](https://commonmark.org/)
- Вложенные списки
  - Ещё один пункт
- ~~Зачёркнутый текст~~

### Список задач

- [x] Открыть один файл
- [x] Обновлять страницу после сохранения

#include <iostream>

### Таблица

| Команда | Действие |
|:--------|:---------|
| `mdread notes.md` | Открыть заметку |
| `Ctrl+C` | Остановить сервер |

> Хороший ридер помогает сосредоточиться на тексте.
