## Бюджеты

- Исходник/локальное изображение: 16 MiB. HTML: 4 MiB и 40000 символов `<`
  (консервативная оценка числа тегов). JSON-строка: 8 MiB.
- Итоговый DOM до вставки в статью: 60000 узлов, включая KaTeX.
- Не более 200 формул; одна — 8192 UTF-16 единицы и 128 уровней вложенности;
  суммарный вход — 262144 единицы. Раскрытие макросов — до 200.
- Результат одной формулы — 256 Ki единиц, суммарный math markup — 2 Mi единиц;
  сверх бюджета формула остаётся текстом. Работа уступает UI после каждых 8 формул.
- Кэш контента: до 16 записей и 32 MiB сериализованных ответов. Кэш папок: до 8
  записей по максимум 8 MiB. Переполнение освобождает кэш; ETag не зависит от порядка запросов.
- Папка: до 100000 просмотренных записей и 50000 отображаемых файлов/подпапок.
- Активный опрос контента: 0.6–2 сек, при ошибке backoff до 5 сек; список — не чаще
  раза в 2 сек, при ошибке до 30 сек. Фоновая страница запросы не выполняет.

Используются переносимые метаданные и периодическая контрольная сверка вместо
платформенных watcher API. Изменения обычно обнаруживаются по ctime/inode сразу;
при одинаковых метаданных сверка с содержимым выполняется через максимум 10 секунд
активного опроса. Точное время зависит от файловой системы и длительности обработки.

Срок сокета проверяется между операциями; зависшее ядровое чтение сетевой ФС
не может быть жёстко прервано этим механизмом. Установленные бюджеты — границы
работы приложения, не гарантия времени кадра или абсолютного RSS любого WebKit.

## Воспроизведение

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON -DMDREAD_TEST_NATIVE_WINDOW=ON
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure

cmake -S . -B build/sanitized -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON -DMDREAD_SANITIZERS=ON
cmake --build build/sanitized --parallel 2
UBSAN_OPTIONS=halt_on_error=1 ctest --test-dir build/sanitized -R '^integration$' --output-on-failure
```

Проверки на macOS используют настоящие TCP-соединения и WKWebView, а не подмену
системных функций. `review_window` отдельно проверяет adversarial-сценарии браузера.
Хэши библиотек и установщик проверяются отдельными тестами.

Локальный результат: Release — **6/6** CTest-наборов успешно (23.71 с);
Debug с ASan/UBSan — HTTP-интеграция успешно (5.56 с), сообщений санитайзеров нет.
Эти времена относятся к одному прогону на текущей машине, не к SLA.

CI подготовлен для macOS/Linux, Release/Debug; Debug использует ASan/UBSan.
Оконные проверки macOS можно включить параметром manual workflow dispatch при
наличии desktop session. CI не запускался из этой ветки без push. Локальный Linux
прогон недоступен: Docker daemon отсутствует. Linux GUI, минимальные старые версии
WebKit, пиковый RSS и аппаратный свайп этим прогоном не подтверждены.

Отдельные предложения из конца аудита — полноценный fuzzing, SBOM/advisory service,
подписанные пакеты, поиск по тексту, печать и экспорт — остаются будущими задачами;
они не выдаются за исправленные баги AD-01…AD-11.
