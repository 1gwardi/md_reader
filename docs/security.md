# Модель доступа mdread

mdread читает файлы с правами запустившего пользователя. Сервер привязан к
`127.0.0.1`, проверяет точный Host и не выдаёт CORS-разрешения. **Аутентификации
локального HTTP-клиента нет**: другой процесс/пользователь этой машины, имеющий
доступ к порту, может запросить открытые документы. Это инструмент локального
просмотра, а не сервер для публикации конфиденциальных файлов или многопользовательская служба.

Корень — открытая папка или родитель одиночного документа. Его дескриптор
удерживается на протяжении сессии. Компоненты путей открываются через `openat`
с `O_NOFOLLOW`, а тип проверяется через `fstat` уже открытого объекта.
Симлинки полностью запрещены. Обычное атомарное сохранение работает.
Имена с `..` разрешены только после нормализации внутри корня. Жёсткие ссылки
рассматриваются как обычные файлы: это граница доступа по именам, не отдельная файловая песочница.

HTML проходит DOMPurify; скрипты и обработчики удаляются, формы не отправляются.
Область документа имеет layout/paint containment и собственный stacking context:
fixed/absolute-элементы и большие z-index не рисуются поверх toolbar и explorer.
Цвета и обычное inline-оформление, таблицы и details сохраняются.
Ссылки открываются в текущем окне ридера; внешние ссылки — в системном браузере.
`target` из HTML удаляется. KaTeX работает с `trust:false` и отдельными бюджетами.

По умолчанию внешние HTTP(S)-изображения разрешены, включая URL из inline CSS.
Они могут сообщить удалённому серверу о просмотре документа. Для запрета таких
автоматических запросов используйте `mdread --offline файл.md`: CSP оставляет
для изображений только текущий origin и `data:`. Пользовательское нажатие внешней
ссылки по-прежнему может открыть браузер. Шрифты и библиотеки ридера встроены в бинарник.

`third_party/SHA256SUMS` и `tools/check_vendored.py` фиксируют 26 поставляемых
артефактов, включая лицензии. Это проверка целостности текущих копий, **не** аудит
CVE или криптографическое подтверждение происхождения upstream. Обновление версии
требует проверки релиза, лицензий, хэшей и регрессионного прогона. Системный WebKit,
MD4C и Homebrew следует обновлять отдельно; установщик Homebrew использует upstream HEAD.
